## 体验与数据说明

- 首次可免登录体验3次成功查询，登录后按账号试用及原会员权益使用；余量以服务实时返回为准。
- 报价保留日期和适用地区，不称成交价或保证在售库存。省级参考明确标注，不冒充本市价格。
- 历史、推演和未来预测分别标识。只有实际返回且通过验证的预测才能作为结果；演示不是真实模型效果。
- 目前部分客户端会员接续、数据覆盖和首查速度仍在完善。付费前请先确认本人客户端能读取会员权益；连接、卡片和会员续查分别验收。
